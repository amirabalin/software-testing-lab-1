# Отчёты о дефектах

## Регистрация пользователя с возрастом 18 лет отклоняется как недопустимая

- Окружение: тестовая версия сервиса регистрации на образовательной платформе.
- Предусловия: пользователь не зарегистрирован в системе; возраст пользователя составляет 18 лет.
- Серьёзность: Высокая
- Приоритет: Высокий

### Шаги воспроизведения

1. Открыть форму регистрации.
2. Заполнить имя корректным значением.
3. Ввести уникальный адрес электронной почты.
4. Ввести корректный пароль.
5. Указать возраст 18 лет.
6. Нажать кнопку «Зарегистрироваться».

### Фактический результат

Система показывает сообщение «Регистрация доступна только с 18 лет», и регистрация не выполняется.

### Ожидаемый результат

Пользователь с возрастом 18 лет должен иметь возможность пройти регистрацию, если остальные введённые данные соответствуют требованиям.

### Дополнительные материалы

Согласно исходному требованию, регистрироваться могут совершеннолетние пользователи. Скриншот дефекта может быть добавлен в каталог evidence/.

## Двойная отправка формы регистрации создаёт две учётные записи

- Окружение: тестовая версия сервиса регистрации на образовательной платформе.
- Предусловия: пользователь не зарегистрирован; введены корректные данные.
- Серьёзность: Высокая
- Приоритет: Высокий

### Шаги воспроизведения

1. Открыть форму регистрации.
2. Заполнить имя.
3. Ввести уникальный адрес электронной почты.
4. Ввести корректный пароль.
5. Указать допустимый возраст.
6. Дважды быстро нажать кнопку «Зарегистрироваться».

### Фактический результат

В системе создаются две учётные записи.

### Ожидаемый результат

При повторной отправке одного и того же запроса должна быть создана не более одной учётной записи.

### Дополнительные материалы

Необходимо приложить скриншот или другой материал, подтверждающий наличие двух созданных учётных записей.

## При регистрации с существующим email техническое сообщение раскрывает данные пользователя

- Окружение: тестовая версия сервиса регистрации на образовательной платформе.
- Предусловия: в системе уже существует пользователь с указанным адресом электронной почты.
- Серьёзность: Высокая
- Приоритет: Высокий

### Шаги воспроизведения

1. Открыть форму регистрации.
2. Ввести существующий в системе адрес электронной почты.
3. Заполнить остальные обязательные поля корректными значениями.
4. Нажать кнопку «Зарегистрироваться».

### Фактический результат

Система показывает техническое сообщение об ошибке, содержащее полный объект существующего пользователя.

### Ожидаемый результат

Система должна сообщить об ошибке регистрации без раскрытия персональных и технических данных существующего пользователя.

### Дополнительные материалы

Необходимо приложить скриншот технического сообщения с раскрытием данных пользователя.
