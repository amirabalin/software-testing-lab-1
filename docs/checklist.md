# Чек-лист функциональных проверок

## Имя пользователя

- [ ] При вводе корректного имени форма принимает значение.
- [ ] При оставленном пустым поле имени система сообщает о необходимости заполнения.
- [ ] При вводе имени, содержащего недопустимые символы, система сообщает об ошибке.
- [ ] При вводе слишком короткого имени система корректно обрабатывает значение согласно согласованному ограничению.
- [ ] При вводе имени на границе допустимой длины система обрабатывает значение согласно согласованному ограничению.

## Адрес электронной почты

- [ ] При вводе корректного адреса электронной почты форма принимает значение.
- [ ] При оставленном пустым поле email система сообщает о необходимости заполнения.
- [ ] Форма отклоняет адрес без имени пользователя до символа @.
- [ ] Форма отклоняет адрес без доменной части.
- [ ] Форма отклоняет адрес без символа @.
- [ ] При вводе уже зарегистрированного email система отклоняет регистрацию и сообщает причину.
- [ ] При вводе email в различном регистре система обрабатывает уникальность согласно согласованному правилу.
- [ ] Сообщение об ошибке email не содержит персональные данные другого пользователя.

## Пароль

- [ ] При вводе пароля, соответствующего установленным требованиям, форма принимает значение.
- [ ] При оставленном пустым поле пароля система сообщает о необходимости заполнения.
- [ ] Пароль, не соответствующий минимальной длине, отклоняется.
- [ ] Пароль на границе минимальной допустимой длины обрабатывается согласно установленному правилу.
- [ ] Пароль, содержащий требуемые типы символов, принимается согласно установленным требованиям.
- [ ] При некорректном пароле пользователь получает понятное сообщение об ошибке.

## Возраст

- [ ] При указании возраста 18 лет регистрация разрешается.
- [ ] При указании возраста больше 18 лет регистрация разрешается.
- [ ] При указании возраста 17 лет регистрация отклоняется.
- [ ] При указании возраста меньше 18 лет отображается понятное сообщение.
- [ ] При оставленном пустым поле возраста система сообщает о необходимости заполнения.
- [ ] При вводе недопустимого значения возраста система сообщает об ошибке.

## Успешная регистрация

- [ ] При заполнении всех корректных данных пользователь успешно регистрируется.
- [ ] После успешной регистрации отображается сообщение об успехе.
- [ ] После успешной регистрации создаётся только одна учётная запись.
- [ ] Данные зарегистрированного пользователя сохраняются корректно.
- [ ] После успешной регистрации система не показывает технические данные или служебную информацию.

## Обработка ошибок

- [ ] При ошибке регистрации пользователь получает понятное сообщение.
- [ ] Сообщение об ошибке указывает причину, достаточную для исправления введённых данных.
- [ ] Технические данные сервера не отображаются пользователю.
- [ ] При недоступности сервиса пользователь получает понятное сообщение.
- [ ] При ошибке данные пользователя не создаются частично или в некорректном состоянии.

## Повторная отправка формы

- [ ] При двойном нажатии кнопки регистрации создаётся не более одной учётной записи.
- [ ] При повторной отправке уже успешно обработанной формы система предотвращает создание дубликата.
- [ ] Во время обработки запроса пользователь получает понятное состояние формы.
- [ ] Повторная отправка формы не приводит к потере или повреждению введённых данных.
- [ ] При повторной отправке формы с уже зарегистрированным email система сообщает о существовании учётной записи.
